# E-commerce Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Excel. An interactive dashboard was created to summarize key business metrics and explore sales performance.

## Tools & Skills
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis and Visualization

## Key Metrics
- Total Revenue
- Total Profit
- Product Performance
- Monthly Revenue Trends
- Revenue Distribution by Product

![E-commerce Sales Dashboard](dashboard-preview.png)

## Project Files
- `Ecommerce_Sales_Analysis.xlsx`: Excel workbook containing the analysis and dashboard.
- `dashboard-preview.png`: Preview image of the dashboard.

## Project Purpose
This is a portfolio project created to practice and demonstrate Excel data analysis skills.

**Note:** This is a practice project using sample data, not real company data.

## معرفی پروژه به فارسی

در این پروژه، با استفاده از Microsoft Excel یک داشبورد تعاملی برای بررسی عملکرد فروش طراحی شده است.

### ابزارهای استفاده‌شده
- Excel
- PivotTable و PivotChart
- Slicer برای فیلتر کردن اطلاعات

### هدف پروژه
بررسی شاخص‌های فروش و سود، مقایسه عملکرد محصولات و نمایش روند درآمد در قالب نمودارها و شاخص‌های کلیدی.

این پروژه با داده‌های تمرینی ساخته شده و نمونه‌ای از تمرین مهارت‌های تحلیل داده است.
